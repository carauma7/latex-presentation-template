# 🇺🇸 English Version

## 🚀 Turn Your Presentations into Geometric Art

**Mondrian Presentation** is a minimalist LaTeX Beamer template inspired by the artistic language of Piet Mondrian.

Combining geometric composition, bold black lines, and the iconic primary colors — red, blue, and yellow — this template brings a distinctive visual identity to academic and technical presentations.

*Simplicity is the ultimate sophistication.*

## ✨ Key Features

- **Mondrian-Inspired Design:** Geometric layouts with strong black lines and carefully balanced compositions.
- **Primary Color Palette:** Red, blue, yellow, black, and white, following a consistent visual rule: colored blocks never touch directly.
- **Minimalist Aesthetics:** Clean backgrounds, generous whitespace, and elegant typography.
- **Widescreen Format:** 16:9 aspect ratio, designed for modern presentations.
- **Custom Graphics:** Built-in TikZ and PGFPlots support for diagrams, charts, and mathematical illustrations.
- **Code Highlighting:** Specialized layouts for C code and pseudocode.
- **Academic Ready:** Suitable for technical lectures, research presentations, and university projects.
- **Fully Editable:** Customize colors, titles, sections, diagrams, and content directly in LaTeX.

## 🔧 Quick Start

Clone the repository:

\`\`\`bash
git clone https://github.com/carauma7/latex-presentation-template.git

cd latex-presentation-template

# 🇧🇷 Versão em Português

## 🚀 Transforme Suas Apresentações em Arte Geométrica

**Mondrian Presentation** é um template minimalista para LaTeX Beamer inspirado na linguagem artística de Piet Mondrian.

Combinando composição geométrica, linhas pretas marcantes e as icônicas cores primárias — vermelho, azul e amarelo —, o modelo oferece uma identidade visual própria para apresentações acadêmicas e técnicas.

*A simplicidade é o auge da sofisticação.*

## ✨ Recursos Principais

- **Design inspirado em Mondrian:** Composições geométricas, linhas pretas marcantes e distribuição equilibrada dos elementos.

- **Estética Minimalista:** Fundos claros, espaços bem distribuídos e tipografia elegante.
- **Formato Widescreen:** Proporção 16:9, ideal para apresentações modernas.
- **Elementos Gráficos Personalizados:** Suporte integrado a TikZ e PGFPlots para diagramas, gráficos e ilustrações matemáticas.
- **Destaque de Código:** Estruturas preparadas para apresentar códigos em C e pseudocódigos.
- **Pronto para Uso Acadêmico:** Ideal para aulas, seminários, pesquisas e trabalhos universitários.
- **Totalmente Editável:** Personalize cores, títulos, seções, diagramas e conteúdos diretamente no LaTeX.

# 🇨🇳 中文版本

## 🚀 将你的演示文稿变成几何艺术

**Mondrian Presentation** 是一款以艺术家蒙德里安（Piet Mondrian）的艺术风格为灵感设计的极简主义 LaTeX Beamer 演示文稿模板。

通过几何构图、醒目的黑色线条以及经典的三原色——红色、蓝色和黄色，这款模板为学术和技术演示带来独特的视觉风格。

*简约，是优雅与精致的最高境界。*

## ✨ 主要特点

- **蒙德里安风格设计：** 采用几何布局、醒目的黑色线条以及精心平衡的画面构成。
- **经典三原色：** 使用红色、蓝色、黄色、黑色和白色，并遵循统一的视觉原则：不同颜色的色块不会直接相接。
- **极简美学：** 明亮的背景、合理的留白以及优雅的字体。
- **宽屏格式：** 采用 16:9 屏幕比例，适合现代演示环境。
- **自定义图形：** 集成 TikZ 和 PGFPlots，支持绘制示意图、数据图表和数学插图。
- **代码高亮：** 提供适合展示 C 语言代码和伪代码的排版样式。
- **适用于学术场景：** 适合技术讲座、研究报告、课程展示和大学项目。
- **完全可编辑：** 可直接使用 LaTeX 自定义颜色、标题、章节、图表和演示内容。
